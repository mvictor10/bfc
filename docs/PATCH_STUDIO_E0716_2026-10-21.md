# Correção de compilação BFC Studio — E0716

Data: 21/10/2026

## Erro corrigido

O compilador reportava `E0716: temporary value dropped while borrowed` em `src/bin/bfc_studio.rs`, ao passar uma referência a `voice_file.display().to_string()` diretamente de um ramo de `if`.

## Alteração

O caminho de voz agora é materializado em uma variável `String` local (`voice_path`) antes da chamada a `set_text`:

```rust
let voice_path = if voice_file.is_file() {
    voice_file.display().to_string()
} else {
    String::new()
};
set_text(C_VOICE, &voice_path);
```

Isso mantém o valor vivo durante a chamada e evita uma referência a uma string temporária que expira no fim da expressão condicional. Nenhuma regra funcional de carregamento da voz foi alterada.

## Validação

O código-fonte e o ZIP foram verificados estruturalmente. Não foi possível executar `cargo build --release` neste ambiente porque `cargo`/`rustc` não estão instalados. Recompile no Windows com `build.bat` para confirmar a toolchain local.
